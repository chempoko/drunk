# 🔧 Последние изменения

## ✅ Исправленные проблемы:

### 1. **"Мой прогресс" показывал "Аскеза не начата"**
   - **Проблема**: Функция проверяла `if days == 0` вместо проверки активности аскезы
   - **Решение**: Добавлена функция `is_abstinence_active()` которая проверяет наличие `started_at` и отсутствие `last_drink` после него

### 2. **"Выпить" не сбрасывал счетчик**
   - **Проблема**: Условие `if days_passed == 0` блокировало действие для новых аскез (< 1 дня)
   - **Решение**: Использована проверка `is_abstinence_active()` вместо проверки количества дней

### 3. **Добавлена групповая статистика**
   - Новая функция `get_group_stats()` собирает статистику всех активных пользователей
   - Кнопка "📈 Статистика" теперь показывает:
     - 🏆 Лидеры по дням (с медалями 🥇🥈🥉)
     - 👥 Общее количество участников
     - 👤 Твоя позиция в рейтинге

### 4. **Кнопка "📊 Мой прогресс" показывает только твою статистику**
   - Личная информация о количестве дней
   - Мотивирующие сообщения в зависимости от прогресса

## 📊 Новые функции в db.py:

```python
is_abstinence_active(user_id)       # Проверяет активна ли аскеза
get_group_stats()                    # Возвращает статистику всей группы
get_all_active_users()               # Возвращает всех пользователей с активной аскезой
```

## 🎯 Как это работает:

1. **Счетчик дней**: `datetime.now().date() - started.date()` (полные календарные дни)
2. **Активная аскеза**: `started_at` установлен И `last_drink` NULL или раньше `started_at`
3. **Обнуление**: При нажатии "Выпить" устанавливается `last_drink = NOW()`, что де-активирует аскезу

## ✨ Особенности:

- ✅ Если прошло меньше 1 дня - показывает 0 дней
- ✅ Пользователь видит только свою статистику на "Мой прогресс"
- ✅ Все пользователи чата видят групповой рейтинг на "Статистика"
- ✅ После "Выпить" пользователь исключается из рейтинга пока не начнет новую аскезу
